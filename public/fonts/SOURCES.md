# Font assets

Downloaded 2026-10-23 from the official Google Fonts CSS API and fonts.gstatic.com.
Files are unmodified Latin WOFF2 subsets; both families use the SIL Open Font License 1.1.
The complete licenses and copyright notices are included alongside the font files.

- `dm-sans-latin-wght-400-700.woff2`: DM Sans variable weight 400–700, https://fonts.gstatic.com/s/dmsans/v17/rP2Yp2ywxg089UriI5-g4vlH9VoD8Cmcqbu0-K4.woff2
- `barlow-condensed-latin-500.woff2`: Barlow Condensed medium 500, https://fonts.gstatic.com/s/barlowcondensed/v13/HTxwL3I-JCGChYJ8VI-L6OO_au7B4-Lwz3bWuQ.woff2
- `barlow-condensed-latin-600.woff2`: Barlow Condensed semibold 600, https://fonts.gstatic.com/s/barlowcondensed/v13/HTxwL3I-JCGChYJ8VI-L6OO_au7B4873z3bWuQ.woff2

Only weights used by the site are bundled. Chinese text uses the existing local system font stack.
